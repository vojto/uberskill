# Repository Instructions
## 📝 Markdown Formatting
- Do not insert blank lines when creating or editing Markdown files.
- Remove existing blank lines from every Markdown file you edit.
- Keep level 2 headings (`##`) as the section boundaries.
- Add a relevant emoji to every level 2 heading.
- Insert a horizontal rule (`***`) between consecutive level 2 sections.
***
## 🧹 Cleanup
- Fix obvious formatting debris, inconsistent heading capitalization, trailing whitespace, grammar, and punctuation while preserving meaning.
