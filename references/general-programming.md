# General Programming
## ✨ Simplicity
1. Always pick the simpler solution requiring less code.
2. Don't prematurely try to handle all edge cases. Start with the simpler solution and ask the user whether they want to handle specific edge cases before introducing complexity.
***
## ❓ Boolean Naming
All booleans should be prefixed with `is`, `was`, `wants`, `has`, or a similar predicate prefix. This applies to booleans in code and database fields.
Example: use `wantsAutoUpdate` instead of `autoUpdate`.
***
## 🪵 Logging
1. When I ask you to add logging to debug a specific problem, add only the minimum needed to debug the issue. Don't add extra log messages just for good measure.
